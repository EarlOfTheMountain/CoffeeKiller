# Roadmap — The Coffee Killer

Small, shippable milestones. Each one should be playable end-to-end.

## v0.1 — the walking demo ✅

- [x] Fixed-timestep loop, pixel-perfect renderer, keyboard input
- [x] Scene system: boot → title → world
- [x] Tilemap with ASCII levels, AABB tile collision, follow camera
- [x] Caffeine meter draining (CoffeeSystem stub with buff/crash multipliers)
- [x] Placeholder art generated by script

## v0.2 — zombies & the mop

- [ ] Zombie entity: wander → aggro → chase AI (line of sight)
- [ ] Mop melee: swing arc, knockback, i-frames, floating damage numbers
- [ ] Player health (3 hearts, Zelda rules) + hit feedback
- [ ] Zombie contact damage; death → respawn at café door

## v0.3 — coffee economy

- [ ] Coffee cup pickups on the map (`drink()` is already wired in CoffeeSystem)
- [ ] Brew tiers: Espresso (speed), Cold Brew (attack up), Double Shot (both + harder crash)
- [ ] Crash event: screen wobble, slow walk, "so... sleepy..." overlay
- [ ] Bean sacks as destructible/lootable props

## v0.4 — comedy delivery

- [ ] Typewriter dialogue box (NPCs with quest hooks, zombie pickup lines)
- [ ] Signposts that lie to you
- [ ] Ambient gags (random floating thoughts, security skeleton with a mug)

## v0.5 — structure & persistence

- [ ] Day counter + difficulty ramp per day
- [ ] Save/load to localStorage (caffeine level, day, zombies mopped)
- [ ] Proper game over / statistics screen ("zombies caffeinated: 0")

## v0.6+ — dreams

- [ ] Gamepad support (Gamepad API)
- [ ] A real bitmap pixel font
- [ ] Real sprite art to replace the generated placeholders
- [ ] Mini-boss: The Decaf Baron
