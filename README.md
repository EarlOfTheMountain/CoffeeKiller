# The Coffee Killer ☕🧟

> _The apocalypse happened. The café stayed open._

A light Zelda-like action game with a comedy heart, written in **plain
JavaScript** on **vanilla Canvas 2D** — no game engine, no runtime
dependencies. You play **The Coffee Killer**, a barista surviving the zombie
apocalypse where caffeine is the only real power source. Zombies everywhere,
but the true enemy is decaf.

This is **v0.1 — the walking demo**: boot → title screen → one explorable map
with tile collision, a following camera and a slowly draining caffeine meter.

---

## Getting started (Debian)

The only prerequisite is **Node.js ≥ 20.19** (22 LTS recommended). The
`nodejs` package in Debian stable is usually too old, so use either:

```bash
# option A: NodeSource
curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -
sudo apt-get install -y nodejs

# option B: nvm
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.3/install.sh | bash
nvm install 22 && nvm use 22
```

Then:

```bash
npm install
npm run dev        # → http://localhost:5173
```

## Scripts

| Command           | What it does                                                                          |
| ----------------- | ------------------------------------------------------------------------------------- |
| `npm run dev`     | Vite dev server with hot reload (localhost:5173)                                      |
| `npm run build`   | Production build → `dist/` (portable, `base: './'`)                                   |
| `npm run preview` | Serve the production build locally                                                    |
| `npm run lint`    | ESLint                                                                                |
| `npm run format`  | Prettier (write)                                                                      |
| `npm run assets`  | Regenerate all placeholder art (needs python3-pillow: `sudo apt install python3-pil`) |
| `npm run smoke`   | Headless logic test: level parsing + collision + coffee decay                         |

### Where to add things

- **New map** → copy `src/world/levels/level01.js`, edit the ASCII art
  (legend is at the top of the file and in `src/config.js`).
- **New tile** → add to `TILE_ORDER` in `scripts/generate_assets.py`, add an
  id in `TILES` + legend char in `config.js`, run `npm run assets`.
- **Tuning** → everything lives in `src/config.js` (walk speed, caffeine
  drain, buff multipliers...).

## Placeholder art

All sprites/tiles are generated by `scripts/generate_assets.py` from pixel
maps defined in the file — deterministic, versionable, and easy to redraw.
When real art arrives, replace the PNGs in `public/assets/` and nothing in
code needs to change (frame layout is documented in `src/config.js`).
